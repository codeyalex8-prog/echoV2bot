# Your server key
The **server key** proves to the API which ER:LC private server you mean. Whoever holds it can read your server and send commands, so treat it like a password.

**Where to find it**
1. Join your ER:LC **private server** on Roblox
2. Open the **settings** inside the game
3. Search for **API key** under the **ER:LC API** header
4. Copy the key

If you do not see it, the API pack may not be enabled on that private server. Check the server's owner and the official PRC docs.

**Keep it safe**
- Put it in `.env` as `ERLC_SERVER_KEY`, never in your code
- Never paste it in Discord, a screenshot, a video or GitHub
- If it leaks, generate a new one in the same settings screen and update `.env`
- Only give your bot access to people you trust. Anyone who can run your code can read the key

**One key = one server**
Each private server has its own key. If you run several servers (main, training, academy), you will store one key per server. Page 12 shows how.

**Global keys**
PRC can issue a **global API key** to large applications that serve many servers. Normal bots do not need one. If you ever get one, it goes in a different header (`Authorization`) and has its own rules, so read their docs before using it.

**Test that you have it right**
The key is a long random string. If you accidentally paste spaces or quotes into `.env`, every request will fail with **403**. Paste it with no quotes and no spaces.

Checkpoint: `ERLC_SERVER_KEY` is in `.env` and `.env` is in `.gitignore`.
