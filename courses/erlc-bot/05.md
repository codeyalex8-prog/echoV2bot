# A reusable API client
Instead of repeating `fetch` everywhere, make one helper in **src/erlc.js** that adds the key, handles errors and respects rate limits.
```js
const BASE = 'https://api.policeroleplay.community/v1';
const sleep = ms => new Promise(r => setTimeout(r, ms));

async function erlc(path, { method = 'GET', body, key = process.env.ERLC_SERVER_KEY, tries = 3 } = {}) {
  for (let attempt = 1; attempt <= tries; attempt++) {
    let res;
    try {
      res = await fetch(`${BASE}${path}`, {
        method,
        headers: { 'Server-Key': key, 'Content-Type': 'application/json' },
        body: body ? JSON.stringify(body) : undefined,
        signal: AbortSignal.timeout(10000),
      });
    } catch (e) {
      if (attempt === tries) throw new Error('Could not reach the ER:LC API.');
      await sleep(1500); continue;
    }

    if (res.status === 429) {                       // rate limited
      const data = await res.json().catch(() => ({}));
      const wait = (Number(data.retry_after) || Number(res.headers.get('retry-after')) || 5) * 1000;
      await sleep(Math.min(wait, 15000)); continue;
    }
    if (res.status === 403) throw new Error('The server key was rejected (403). Check ERLC_SERVER_KEY.');
    if (!res.ok) {
      if (attempt === tries) throw new Error(`ER:LC API error ${res.status}.`);
      await sleep(1500); continue;
    }
    const text = await res.text();
    return text ? JSON.parse(text) : null;          // some endpoints return no body
  }
}
module.exports = { erlc };
```
**Rate limits in plain words**
The API limits how fast you can call it, and some routes are stricter. Sending commands is limited to roughly one request every five seconds (this can change), and each limit is tracked per server key. The reply tells you how long to wait, which is what the code above does.

**Cache to stay friendly**
If ten people run `/players` at once, do not make ten requests. Keep the last answer for about 10 to 15 seconds:
```js
const cache = new Map();
async function cached(path, ms = 10000) {
  const hit = cache.get(path);
  if (hit && Date.now() - hit.at < ms) return hit.data;
  const data = await erlc(path);
  cache.set(path, { at: Date.now(), data });
  return data;
}
module.exports.cached = cached;
```
Checkpoint: `require('../src/erlc')` works and returns your server info.
