# Project ideas
**Starter**
- `/server` status and `/players` list (you built these)
- **Auto status message** that edits itself every minute
- **Join code button** shown only to verified members

**Staff tools**
- **Command log watcher** that alerts owners when a non-staff Roblox ID runs an admin command
- **Mod call alerts** pinging a role with the caller and location info you receive
- **Session manager** with start, announce and end buttons
- **Shift tracker:** log when linked staff join and leave, with weekly totals

**Community**
- **Linked profiles:** `/whois @member` showing in-game status
- **Session reminders:** members press Interested and get a DM when it opens
- **Leaderboards** for sessions attended or kills (fun servers)

**Advanced**
- **Multi-server support** with one key per Discord server
- **Dashboard website** for staff stats
- **Ban sync** that lists server bans and cross-checks Discord bans
- **Health monitor** that alerts you when the API fails repeatedly

**How to choose**
Ask staff what takes them the most time, then automate that first. A tool people use daily beats a clever one nobody needs.
