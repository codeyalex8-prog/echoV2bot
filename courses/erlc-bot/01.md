# Welcome to ER:LC bot development
ER:LC (Emergency Response: Liberty County) private servers can be connected to a Discord bot through the **PRC API**. That lets your community see and control the server without ever opening Roblox.

**What ER:LC bots usually do**
- Show live server status: name, players online, queue
- List who is in the server and which team they are on
- Post join, leave, kill and command logs to staff channels
- Send in-game commands (like announcements) from Discord
- Run session announcements with buttons
- Link Discord accounts to Roblox accounts

**What you need**
- An ER:LC **private server** you own or manage, with the ER:LC API available in its settings
- Node.js 18 or newer and a code editor
- A Discord bot already created and invited. If you haven't done that, follow the **Discord Bot Development** pack first (pages 2 to 8 cover it)

**How the API works in one minute**
Your bot sends normal web requests to `https://api.policeroleplay.community/v1/...` and puts your **server key** in a header called `Server-Key`. The API answers with JSON. That's all. Everything in this course is built from that one idea.

**The road ahead**
Pages 2 to 5 get you connected, pages 6 to 9 build real commands, pages 10 and 11 add logs and account linking, and page 12 is hosting and safety.

Important: the API is run by PRC, not by us. Details can change, so when something looks different, check their official docs (the Videos and links menu has the address).
