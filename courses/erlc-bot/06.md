# Command: /server
Show live server status in Discord. **commands/server.js**
```js
const { SlashCommandBuilder, EmbedBuilder } = require('discord.js');
const { cached } = require('../src/erlc');

module.exports = {
  data: new SlashCommandBuilder().setName('server').setDescription('Show the ER:LC server status'),

  async execute(interaction) {
    await interaction.deferReply();                       // the API can be slow
    let s;
    try { s = await cached('/server'); }
    catch (e) { return interaction.editReply(`Could not load the server: ${e.message}`); }

    const queue = await cached('/server/queue').catch(() => []);

    const embed = new EmbedBuilder()
      .setTitle(s.Name || 'ER:LC Server')
      .setColor(0x2b2d31)
      .addFields(
        { name: 'Players', value: `${s.CurrentPlayers}/${s.MaxPlayers}`, inline: true },
        { name: 'Queue', value: String(queue.length), inline: true },
        { name: 'Join code', value: s.JoinKey ? `\`${s.JoinKey}\`` : 'Hidden', inline: true },
      )
      .setTimestamp();
    await interaction.editReply({ embeds: [embed] });
  },
};
```
Run `node deploy-commands.js`, restart, and use `/server`.

**Why `deferReply()`?** Discord gives you only 3 seconds. A web request can take longer, so you tell Discord "working on it" first, then `editReply`.

**Check what fields you have.** Field names come from the API. If a field shows `undefined`, print the object (`console.log(s)`) and use the exact name you see. Names are case sensitive.

**Make it nicer**
- Colour the embed green if players > 0 and grey if empty
- Add a button that refreshes the data
- Auto-update a pinned status message every minute (page 12 shows the timer idea)

**Be careful with the join code.** If your server is private, only show the code in a staff channel. Restrict the command with `.setDefaultMemberPermissions(...)` or check a role in code.

Checkpoint: `/server` shows your live player count.
