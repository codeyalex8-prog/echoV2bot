# Session panel with buttons
A session panel lets staff open a session and let members react. A simple version with buttons:
```js
const { ActionRowBuilder, ButtonBuilder, ButtonStyle, EmbedBuilder, MessageFlags } = require('discord.js');

function panel(session) {
  const embed = new EmbedBuilder()
    .setTitle('ER:LC Session')
    .setDescription(session.open ? 'The session is open. Press Join to be notified.' : 'The session has ended.')
    .addFields({ name: 'Interested', value: String(session.interested.length) })
    .setColor(session.open ? 0x57f287 : 0xed4245);
  const row = new ActionRowBuilder().addComponents(
    new ButtonBuilder().setCustomId('sess_join').setLabel('Interested').setStyle(ButtonStyle.Secondary).setDisabled(!session.open),
    new ButtonBuilder().setCustomId('sess_end').setLabel('End session').setStyle(ButtonStyle.Secondary).setDisabled(!session.open),
  );
  return { embeds: [embed], components: [row] };
}
```
**Handling the buttons** (inside `InteractionCreate`)
```js
if (i.isButton() && i.customId.startsWith('sess_')) {
  const s = sessions.get(i.message.id);
  if (!s) return i.reply({ content: 'That session is gone.', flags: MessageFlags.Ephemeral });

  if (i.customId === 'sess_join') {
    if (!s.interested.includes(i.user.id)) s.interested.push(i.user.id);
    return i.update(panel(s));                       // edit the same message
  }
  if (i.customId === 'sess_end') {
    if (!i.member.permissions.has('ManageMessages')) return i.reply({ content: 'Staff only.', flags: MessageFlags.Ephemeral });
    s.open = false;
    return i.update(panel(s));
  }
}
```
**Ideas to extend it**
- A `/session start` command that posts the panel and pings a role
- Show live players from `/server` on the panel and refresh it each minute
- DM everyone in `interested` when the session opens
- Log session length and peak players for staff stats
- Only show the join code to members who pressed Interested (use an ephemeral reply)

**Store sessions in a file** (page 13 of the Discord bot pack shows `data.json`) so a restart does not lose open sessions. Remember message IDs are strings, so keep them as keys.

Checkpoint: pressing Interested updates the count on the message.
