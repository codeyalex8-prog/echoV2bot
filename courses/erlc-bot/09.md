# Logs: joins, kills and commands
Staff love automatic logs. The idea: **ask the API every so often, remember what you already posted, and send only the new entries.**

Each log entry has a **Timestamp** in unix seconds. Keep the newest one you have seen.
```js
const { erlc } = require('./erlc');
const { EmbedBuilder } = require('discord.js');

let lastJoin = Math.floor(Date.now() / 1000);       // start from "now" so we don't flood old logs

async function pollJoins(client) {
  const channel = await client.channels.fetch(process.env.JOIN_LOG_CHANNEL_ID).catch(() => null);
  if (!channel) return;
  const logs = await erlc('/server/joinlogs').catch(() => null);
  if (!logs) return;

  const fresh = logs.filter(l => l.Timestamp > lastJoin).sort((a, b) => a.Timestamp - b.Timestamp);
  for (const l of fresh) {
    const [name, id] = String(l.Player).split(':');
    await channel.send({ embeds: [new EmbedBuilder()
      .setColor(l.Join ? 0x57f287 : 0xed4245)
      .setDescription(`**${name}** ${l.Join ? 'joined' : 'left'} <t:${l.Timestamp}:R>`)
      .setFooter({ text: `Roblox ID ${id}` })] });
    lastJoin = Math.max(lastJoin, l.Timestamp);
  }
}
module.exports = { pollJoins };
```
Start it when the bot is ready:
```js
const { pollJoins } = require('./src/logs');
client.once(Events.ClientReady, c => setInterval(() => pollJoins(c).catch(console.error), 20000));
```
**Same pattern for the others**
- `/server/killlogs`: killer and victim
- `/server/commandlogs`: who ran which command (great for catching abuse)
- `/server/modcalls`: moderator calls, ping your staff role for new ones

**Avoid duplicates and floods**
- Keep `last...` in `data.json` so a restart doesn't repost
- Poll every 15 to 30 seconds, not every second
- Send at most about 10 messages per poll, summarise the rest
- Never ping roles on every log, only on mod calls

**Command logs as a security tool:** compare commands against a list of staff Roblox IDs. If someone outside it runs an admin command, alert your owners.

Checkpoint: a test join shows up in your log channel within half a minute.
