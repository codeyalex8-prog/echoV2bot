# Command: /players
List who is in the server. **commands/players.js**
```js
const { SlashCommandBuilder, EmbedBuilder } = require('discord.js');
const { cached } = require('../src/erlc');

const parse = p => { const [name, id] = String(p.Player).split(':'); return { ...p, name, id }; };

module.exports = {
  data: new SlashCommandBuilder().setName('players').setDescription('Who is in the server right now'),

  async execute(interaction) {
    await interaction.deferReply();
    const list = (await cached('/server/players').catch(() => null))?.map(parse);
    if (!list) return interaction.editReply('Could not load the player list.');
    if (!list.length) return interaction.editReply('The server is empty.');

    const lines = list.map(p => `[${p.name}](https://www.roblox.com/users/${p.id}/profile)${p.Team ? ` - ${p.Team}` : ''}`);
    const embed = new EmbedBuilder()
      .setTitle(`Players (${list.length})`)
      .setDescription(lines.join('\n').slice(0, 4000))
      .setColor(0x2b2d31);
    await interaction.editReply({ embeds: [embed] });
  },
};
```
**Understanding the data**
Each player comes as text like `Username:123456789`, so we split it on the colon to get the name and the Roblox user ID. Other fields (permission level, team, callsign) are also provided, so print one object to see what your server returns.

**Linking to a profile:** `https://www.roblox.com/users/ID/profile` always opens that player's page.

**Long lists**
Embed descriptions are limited to 4096 characters. With 40+ players, group by team:
```js
const byTeam = {};
for (const p of list) (byTeam[p.Team || 'Unknown'] ??= []).push(p.name);
const fields = Object.entries(byTeam).map(([team, names]) => ({
  name: `${team} (${names.length})`, value: names.join(', ').slice(0, 1000),
}));
```
Then use `.addFields(fields.slice(0, 25))` (an embed can have 25 fields).

**Searching:** add a string option `name` and filter with `list.filter(p => p.name.toLowerCase().includes(query))`, so staff can check if a specific player is online.

Checkpoint: `/players` lists real players with profile links.
