# Your first API request
Create a test file `test.js` and run it with `node test.js`:
```js
require('dotenv').config();

(async () => {
  const res = await fetch('https://api.policeroleplay.community/v1/server', {
    headers: { 'Server-Key': process.env.ERLC_SERVER_KEY },
  });
  console.log('Status code:', res.status);
  console.log(await res.json());
})();
```
**What you should see**
A `200` status and an object describing your server, with fields such as the server name, how many players are in it and the maximum. Print the whole object once so you know exactly what you get back, then use only the fields you need.

**Status codes you will meet**
- `200` worked
- `403` unauthorized: wrong or missing key (check spaces and quotes)
- `429` too many requests: slow down (page 5)
- `500` the API had trouble reaching Roblox, or the server is empty for some actions

**The other endpoints (v1)**
- `GET /server/players` players in the server
- `GET /server/queue` Roblox IDs waiting to join
- `GET /server/joinlogs` joins and leaves
- `GET /server/killlogs` kills
- `GET /server/commandlogs` commands used in game
- `GET /server/modcalls` moderator calls
- `GET /server/bans` banned players
- `GET /server/vehicles` spawned vehicles
- `POST /server/command` run an in-game command

Try them one at a time and print the result. Reading real responses teaches you more than any guide.

Note: PRC has a newer API version in testing. v1 is the public one used in this course. If PRC changes things, their docs always win.
