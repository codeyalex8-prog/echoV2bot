# Linking Discord and Roblox
To know **which Discord member is which player**, you link accounts. The simple, honest version: the member types their Roblox username, and you look up the ID.
```js
async function robloxLookup(username) {
  const res = await fetch('https://users.roblox.com/v1/usernames/users', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ usernames: [username], excludeBannedUsers: true }),
  });
  const data = await res.json().catch(() => null);
  return data?.data?.[0] || null;                    // { id, name, displayName }
}
```
**commands/link.js** (core idea)
```js
const user = await robloxLookup(interaction.options.getString('username'));
if (!user) return interaction.reply({ content: 'Roblox user not found.', flags: MessageFlags.Ephemeral });

const data = load();
data.links ??= {};
const taken = Object.entries(data.links).find(([d, l]) => d !== interaction.user.id && l.robloxId === user.id);
if (taken) return interaction.reply({ content: 'That Roblox account is already linked.', flags: MessageFlags.Ephemeral });

data.links[interaction.user.id] = { robloxId: user.id, name: user.name };
save(data);
```
**Important honesty note:** this only proves the person *typed* a name, not that they own it. For anything sensitive (staff tools, rewards) add proof, such as asking them to put a code you generate into their Roblox profile description and then reading it back through Roblox's user API.

**Using the link**
- In `/players`, show the Discord mention next to linked players
- Give a Discord role when a linked player is in the server
- Cross-check command logs: is the person who ran `:kick` actually staff?
- Show a member's in-game status with `/whois @member`

**Matching IDs:** the API gives IDs as strings inside `Name:Id`, and Roblox returns numbers. Compare with `String(a) === String(b)` so they always match.

**Privacy:** only store what you need (Discord ID, Roblox ID, name), tell members what you store, and offer an `/unlink` command.

Checkpoint: `/link` saves a pair and `/players` can mention linked members.
