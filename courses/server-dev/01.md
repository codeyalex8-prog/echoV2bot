# Welcome: building a server that works
A great Discord server is not about having a hundred channels. It is a **clear purpose**, a **simple layout**, **safe rules** and a **team that keeps it alive**. This pack takes you from an empty server to a launch-ready one.

**What you will build**
- A written plan for your server
- A clean channel and category layout
- A role hierarchy and permissions that don't leak
- Onboarding so new members know what to do
- Moderation, logs and a ticket system
- A launch checklist and a monthly routine

**Before you touch Discord, answer these five questions**
1. **Why does this server exist?** (support, community, a game, a business, a studio)
2. **Who is it for?** (age, interests, skill level)
3. **What should a member do in their first five minutes?**
4. **Who will run it?** (you alone, or a team)
5. **What does "success" look like in 3 months?** (members, activity, sales, tickets solved)

Write the answers down. Every decision later (channels, roles, bots) should serve those answers.

**The golden rule: start small.** It is far easier to add a channel later than to delete empty ones. Dead channels make a server feel dead.

**The roadmap**
2 Server settings, 3 Channels, 4 Roles, 5 Permissions, 6 Onboarding, 7 Moderation, 8 Bots, 9 Tickets, 10 Growth, 11 Staff, 12 Launch and upkeep.

Tip: create a **second private server** to practice in. Break things there, then repeat on your real server.
