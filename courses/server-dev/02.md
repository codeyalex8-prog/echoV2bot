# Server settings that matter
Open **Server Settings** and go through these. They protect you before anyone joins.

**Overview**
- Pick a clear **name** and **icon**
- Set a **System Messages Channel** (the channel where join messages appear). Turn off messages you don't want.

**Safety Setup / Moderation**
- **Verification level:** *Medium* or higher blocks brand-new throwaway accounts. High adds a short wait.
- **Explicit media content filter:** scan messages from **all members**
- Turn on **2FA requirement for moderation** so a hacked mod account can't ban people
- Use Discord's built in **AutoMod** to block spam and bad words, and to send alerts to a staff channel

**Community features**
Turn on **Enable Community** to unlock onboarding, announcement channels, Server Insights and more. Discord will ask for:
- a **Rules channel**
- an **Updates channel** where Discord posts news for admins
- a safe default for notifications

**Default notification setting:** choose **Only @mentions**. "All messages" in a large server is a flood and makes people mute you.

**Invites**
- Set an **invite expiry** instead of permanent links
- Pause or limit invites during raids (Server Settings > Invites)

**Roles and bots**
- Never give **Administrator** to bots you don't fully trust
- Review "Integrations" every month

**Audit Log**
Server Settings > **Audit Log** shows who changed what. Learn to read it; it solves most "who deleted that?" mysteries.

Checkpoint: Community is on, verification is Medium+, AutoMod has at least one rule, and mods need 2FA.
