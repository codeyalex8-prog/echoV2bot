# Launch checklist and upkeep
**Before you open the doors**
- [ ] Purpose, audience and first-five-minutes plan written down
- [ ] Community enabled, rules and updates channels set
- [ ] Verification level Medium or higher, explicit filter on
- [ ] 2FA required for moderators
- [ ] AutoMod rules active, alerts go to staff
- [ ] Channels and categories finalised, topics written
- [ ] Roles ordered correctly, nobody has accidental Administrator
- [ ] Permissions tested with View Server As Role
- [ ] Onboarding and welcome message ready
- [ ] Bots installed, each with minimum permissions and its own role
- [ ] Mod logs and ticket transcripts working
- [ ] Staff briefed, handbook shared
- [ ] First events scheduled

**Soft launch**
Invite 10 to 20 friends first. Ask them to try everything and tell you what confused them. Fix it, then open to everyone.

**Monthly upkeep (30 minutes)**
- Review Audit Log and mod logs for patterns
- Check Integrations and remove unused bots
- Read Server Insights: retention, active members
- Review tickets: top questions go into the FAQ
- Delete or merge dead channels
- Check staff activity and permissions
- Plan next month's events

**Backups**
Use a **server template** (Server Settings > Server Template) to save your layout, roles and settings. Update it after big changes. Keep your own notes for bot settings, which templates don't include.

**When things go wrong**
- Raid: pause invites, raise verification, lock channels, ban in bulk, then review
- Leaked token or hacked mod: remove permissions, reset the bot token, check Audit Log
- Drama: pause the channel (slow mode), move it to private, act on facts

**The long game:** consistent, fair moderation and regular events build a server that lasts.

Congratulations. You now have everything you need to build and run a professional Discord server.
