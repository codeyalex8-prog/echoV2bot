# FAQ and fixes
**How many channels should I start with?** Under 25 and 5 to 7 categories. Add more only when members ask.

**A private channel is visible to everyone.** Check the category override for `@everyone` (View Channel deny) and use View Server As Role to test. Also check no member role has Administrator.

**My bot can't give a role.** The bot's role must be above the role it manages, and it needs Manage Roles.

**Members can't see the rules.** Make sure `@everyone` can View Channel on the rules channel and that it's set as the Rules channel in Community settings.

**How do I stop spam?** Turn on AutoMod (spam and mention spam), raise verification to Medium or higher, and limit who can post links.

**How do I handle a raid?** Pause invites, raise verification to High, lock channels, ban the raiders, then review the Audit Log.

**What is Community mode?** A set of Discord features (onboarding, insights, discovery, announcement channels) you unlock by enabling Community and setting rules and updates channels.

**Do I need verification?** For public servers, yes. It filters throwaway accounts. Keep it light so real members aren't blocked.

**How do I get more active members?** Greet people, hold regular events and answer fast. Growth without retention doesn't last.

**Should I give friends staff roles?** Only if they're reliable and active. Roles are responsibility and a security risk.

**How do I back up my server?** Use a Server Template for the layout and keep your own notes for bot settings.
