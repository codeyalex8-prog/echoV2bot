# Tips
**1. Plan on paper first.** Draw categories and channels before building.

**2. Fewer channels, more activity.** You can always add more later.

**3. Test with View Server As Role.** It shows exactly what members see.

**4. Use categories to manage permissions.** Set them once and let channels sync.

**5. Give the least permissions possible.** Avoid Administrator for staff and bots.

**6. Write channel topics.** One line saying what belongs there.

**7. Keep rules short and numbered.** Mods can then say "Rule 3".

**8. Make ping roles opt-in.** Nobody should be pinged without choosing it.

**9. Log everything staff do.** A private mod log channel is non-negotiable.

**10. Welcome people personally.** A friendly first message keeps new members.

**11. Run regular events.** Weekly beats a huge one-off.

**12. Don't copy huge servers.** Your size and purpose are different.

**13. Review monthly.** Delete dead channels, remove unused bots, check staff activity.

**14. Save a server template** after big changes.

**15. Never buy members.** They don't talk and they hurt your stats.
