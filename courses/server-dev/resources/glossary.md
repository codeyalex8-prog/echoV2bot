# Glossary
**Guild:** Discord's word for a server.

**Category:** a folder that groups channels and can share permissions.

**Channel:** a place to chat (text), talk (voice), post news (announcement), or hold discussions (forum).

**Thread:** a temporary side conversation inside a channel.

**Forum channel:** a channel where each post is its own thread, good for support and suggestions.

**Role:** a set of permissions and a colour you give to members.

**Hierarchy:** the order of roles. Higher roles can manage lower ones.

**Permission override:** a rule on a category or channel that overrides the server-wide role permission.

**@everyone:** the default role that every member has.

**Community server:** a server with Discord's extra tools turned on (onboarding, insights, discovery).

**Onboarding:** the questions and guide new members see when joining.

**Rules screening:** members must accept rules before they can talk.

**Verification level:** how strict Discord is about who can send messages (account age, email, phone).

**AutoMod:** Discord's built-in filter for spam, mentions and chosen words.

**Timeout:** a temporary mute that blocks chatting and joining voice.

**Audit Log:** a record of changes made in the server.

**Server Insights:** Discord's analytics for joins, retention and activity.

**Template:** a saved copy of your layout and settings.

**Ticket:** a private support channel opened by a member.

**Raid:** a sudden flood of bad accounts joining to cause trouble.

**Vanity URL:** a custom invite link, available when the server unlocks it.
