# Step 10: Embeds, buttons and select menus
**commands/panel.js**
```js
const {
  SlashCommandBuilder, EmbedBuilder, ActionRowBuilder,
  ButtonBuilder, ButtonStyle, StringSelectMenuBuilder,
} = require('discord.js');

module.exports = {
  data: new SlashCommandBuilder().setName('panel').setDescription('Show a demo panel'),

  async execute(interaction) {
    const embed = new EmbedBuilder()
      .setTitle('Demo panel')
      .setDescription('Press the button or pick an option.')
      .setColor(0x2b2d31);

    const buttons = new ActionRowBuilder().addComponents(
      new ButtonBuilder().setCustomId('hello').setLabel('Say hello').setStyle(ButtonStyle.Primary),
      new ButtonBuilder().setLabel('Docs').setStyle(ButtonStyle.Link).setURL('https://discord.js.org'),
    );

    const menu = new ActionRowBuilder().addComponents(
      new StringSelectMenuBuilder()
        .setCustomId('colour')
        .setPlaceholder('Pick a colour')
        .addOptions(
          { label: 'Red', value: 'red' },
          { label: 'Blue', value: 'blue' },
        ),
    );

    await interaction.reply({ embeds: [embed], components: [buttons, menu] });
  },
};
```

**Handling the clicks** (add inside your `InteractionCreate` handler, above the slash-command check)
```js
if (interaction.isButton() && interaction.customId === 'hello') {
  return interaction.reply({ content: `Hello ${interaction.user}!`, flags: MessageFlags.Ephemeral });
}
if (interaction.isStringSelectMenu() && interaction.customId === 'colour') {
  return interaction.reply({ content: `You picked ${interaction.values[0]}`, flags: MessageFlags.Ephemeral });
}
```
**Key ideas**
- Each component has a unique `customId` that you match in code
- A message can hold up to **5 rows**; a row holds up to **5 buttons** or **1 select menu**
- Link buttons open a URL and need no handler
- Buttons keep working after a restart as long as your handler matches the `customId`

**Components V2 (the style of this server's panels)**
Newer bots can build layouts with `ContainerBuilder`, `TextDisplayBuilder`, `SeparatorBuilder` and `MediaGalleryBuilder`. Send with `flags: MessageFlags.IsComponentsV2` and put them in `components`. In V2 messages you cannot also send `content` or `embeds`.

**Checkpoint:** `/panel` shows buttons and a menu that both respond.
