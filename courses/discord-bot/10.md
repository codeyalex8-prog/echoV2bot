# Step 9: Options and subcommands
Options let users give your command input.

**commands/userinfo.js**
```js
const { SlashCommandBuilder } = require('discord.js');

module.exports = {
  data: new SlashCommandBuilder()
    .setName('userinfo')
    .setDescription('Shows info about a member')
    .addUserOption(o => o
      .setName('user')
      .setDescription('Who to look up')
      .setRequired(false)),

  async execute(interaction) {
    const user = interaction.options.getUser('user') ?? interaction.user;
    const member = await interaction.guild.members.fetch(user.id).catch(() => null);

    const joined = member ? `<t:${Math.floor(member.joinedTimestamp / 1000)}:R>` : 'unknown';
    const created = `<t:${Math.floor(user.createdTimestamp / 1000)}:R>`;

    await interaction.reply({
      content: `**${user.tag}**\nAccount created: ${created}\nJoined server: ${joined}`,
      allowedMentions: { parse: [] },
    });
  },
};
```
Deploy (`node deploy-commands.js`) and try `/userinfo`.

**Option types**
`addStringOption`, `addIntegerOption`, `addBooleanOption`, `addUserOption`, `addChannelOption`, `addRoleOption`, `addNumberOption`, `addAttachmentOption`.
Read them with `interaction.options.getString('name')`, `getInteger`, `getBoolean`, `getUser`, `getChannel`, `getRole`.

**Useful settings:** `.setRequired(true)`, `.setMaxLength(100)` (strings), `.setMinValue(1)` / `.setMaxValue(10)` (numbers), and `.addChoices({ name: 'Easy', value: 'easy' })` for a fixed list.

**Subcommands** group related actions under one command:
```js
data: new SlashCommandBuilder()
  .setName('todo')
  .setDescription('Your to-do list')
  .addSubcommand(s => s.setName('add').setDescription('Add an item')
    .addStringOption(o => o.setName('text').setDescription('What to do').setRequired(true)))
  .addSubcommand(s => s.setName('list').setDescription('Show your items')),
```
Check which one ran with `interaction.options.getSubcommand()`.

**Limit who can use a command:** `.setDefaultMemberPermissions(PermissionFlagsBits.ManageGuild)` hides it from members without that permission.

**Checkpoint:** `/userinfo` works with and without a user.
