# Step 11: Events and welcome messages
Events are things that happen in your server: a member joins, a message is sent, a role changes. You listen with `client.on(...)`.

**1. Turn on the intent**
Joining members need the **GuildMembers** intent. In **index.js**:
```js
const client = new Client({
  intents: [GatewayIntentBits.Guilds, GatewayIntentBits.GuildMembers],
});
```
And make sure **Server Members Intent** is ON in the Developer Portal (page 3), otherwise the bot refuses to start.

**2. Add the welcome event** in **index.js**
```js
client.on(Events.GuildMemberAdd, async member => {
  const channel = member.guild.channels.cache.get(process.env.WELCOME_CHANNEL_ID);
  if (!channel) return;
  await channel.send(`Welcome to **${member.guild.name}**, ${member}! You are member #${member.guild.memberCount}.`);
});
```
Add `WELCOME_CHANNEL_ID=` to your `.env` (right-click the channel > Copy Channel ID).

**Common events**
- `Events.MessageCreate` (needs the Message Content intent to read text)
- `Events.GuildMemberRemove`: someone left
- `Events.GuildMemberUpdate`: roles or nickname changed
- `Events.MessageDelete`: for logs
- `Events.ChannelCreate`

**Keeping it tidy: event files**
Once you have several events, move each into `events/name.js`:
```js
const { Events } = require('discord.js');
module.exports = {
  name: Events.GuildMemberAdd,
  once: false,
  execute(member) { /* your code */ },
};
```
and load them like the commands (`client.on(event.name, (...args) => event.execute(...args))`).

**Give a role on join**
```js
const role = member.guild.roles.cache.get(process.env.MEMBER_ROLE_ID);
if (role) await member.roles.add(role).catch(console.error);
```
(The bot's role must sit above that role.)

**Checkpoint:** a test account joining your server triggers the welcome message.
