# Step 4: Set up the project
Open your terminal in your projects folder and run:
```
mkdir my-bot
cd my-bot
npm init -y
npm install discord.js dotenv
```
- `npm init -y` creates **package.json**
- `discord.js` is the bot library
- `dotenv` loads secrets from a `.env` file

Open the folder in VS Code (`code .`) and create this structure:
```
my-bot/
├─ commands/
│  └─ ping.js
├─ .env
├─ .gitignore
├─ deploy-commands.js
├─ index.js
└─ package.json
```
(Make the files empty for now, we fill them in the next pages.)

**.env** (replace with your real values, no quotes, no spaces)
```
DISCORD_TOKEN=paste-your-token-here
CLIENT_ID=your-application-id
GUILD_ID=your-server-id
```

**.gitignore** (so secrets never get uploaded)
```
node_modules
.env
data.json
```

**package.json:** add a start script inside `"scripts"`:
```json
"scripts": {
  "start": "node index.js"
}
```
Now `npm start` runs your bot.

**Checkpoint:** the folder has `node_modules`, `package.json`, `.env` and `.gitignore`.
