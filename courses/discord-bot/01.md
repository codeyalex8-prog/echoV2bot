# Welcome and the road ahead
Welcome! Over the next **14 pages** you will build a real Discord bot with **JavaScript (Node.js)** and **discord.js v14**, the most popular bot library. No experience with bots is needed, but basic JavaScript (variables, functions, `if`) helps.

**What you will have at the end**
- A bot that is online in your server
- Slash commands like `/ping` and `/userinfo`
- A panel with buttons and a select menu
- A welcome message for new members
- Data saved to a file so it survives restarts
- Knowledge to host it 24/7

**How this guide works**
Every page is one step. Do them in order, copy the code, run it, and only move on when the step works. If something breaks, the last page has a troubleshooting list.

**The roadmap**
1. Welcome (you are here)
2. Install Node.js and VS Code
3. Create the bot in the Developer Portal
4. Invite the bot to your server
5. Set up the project
6. First login
7. Your first slash command
8. Command loader and deploying
9. Handling interactions
10. Options and subcommands
11. Embeds, buttons and menus
12. Events and welcome messages
13. Saving data
14. Hosting, safety and next steps

**You need:** a computer (Windows, Mac or Linux), a Discord account, and a server where you have **Manage Server** (make a free test server, it's safer than building in your main one).

Ready? Press Next.
