# Step 6: Your first slash command
Slash commands are the modern way to use bots: type `/` and Discord shows a menu. Each command lives in its own file in **commands/**.

**commands/ping.js**
```js
const { SlashCommandBuilder } = require('discord.js');

module.exports = {
  data: new SlashCommandBuilder()
    .setName('ping')
    .setDescription('Replies with the bot latency'),

  async execute(interaction) {
    await interaction.reply(`Pong! ${interaction.client.ws.ping}ms`);
  },
};
```

**The two parts of every command**
- `data` is the command's definition (name, description, options). Discord reads this.
- `execute` is the code that runs when someone uses the command.

**Rules for names:** lowercase, no spaces, up to 32 characters (`/ping`, `/user-info`). Descriptions are up to 100 characters.

**Replying**
- `interaction.reply('text')` answers the command. You **must** reply within **3 seconds** or Discord shows "The application did not respond".
- For slow work (database, web request) use `await interaction.deferReply()` first, then `await interaction.editReply('done')` later.
- Add `flags: MessageFlags.Ephemeral` (import `MessageFlags`) to make a reply visible only to the user:
```js
await interaction.reply({ content: 'Only you see this', flags: MessageFlags.Ephemeral });
```

**Checkpoint:** `commands/ping.js` exists. It won't show in Discord until the next two pages.
