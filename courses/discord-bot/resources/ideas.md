# Project ideas
Pick one and build it. Finishing small projects teaches more than reading.

**Starter (a weekend)**
- **Greeter:** welcomes members and gives a starter role
- **Poll bot:** `/poll question option1 option2` with buttons and live counts
- **Reminder bot:** `/remind 10m take a break` and pings you later
- **Dice and games:** `/roll 2d6`, rock-paper-scissors with buttons

**Intermediate**
- **Warn system:** warnings saved to a file, with `/warnings @user`
- **Ticket bot:** a button opens a private channel, a close button saves a transcript
- **Suggestion board:** `/suggest` posts with vote buttons and staff approve or deny
- **Reaction/button roles:** a panel where members pick their roles

**Advanced**
- **Economy and levels:** XP for chatting, a leaderboard, a shop
- **Moderation suite:** timeouts, bans, case numbers, a log channel
- **Dashboard:** a small website that shows your bot's stats
- **API bot:** connect to a game or web API (the ER:LC pack is an example)

**How to approach any project**
1. Write what it should do in 3 sentences
2. List the commands and what each needs
3. Build the smallest version that works
4. Test with a friend, then improve it
5. Add error handling and logging last
