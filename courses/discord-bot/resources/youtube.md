# Videos and helpful links
The links marked *(search)* open a YouTube search for that exact video, so you always land on the current upload.

**Full beginner videos**
• [How to Build and Deploy Your First Discord Bot](https://www.youtube.com/results?search_query=web+dev+simplified+how+to+build+and+deploy+your+first+discord+bot) *(search)*
Web Dev Simplified, about 26 min. Registering the bot, first code, inviting it, extra code and free deployment.

• [Creating a Discord Bot with JavaScript and Discord.js](https://www.youtube.com/results?search_query=coding+train+creating+a+discord+bot+with+javascript+and+discord.js) *(search)*
The Coding Train, about 33 min. Node project, application, invite, .env, logging in, slash commands and how bots talk to Discord.

• [Discord bot tutorial series](https://www.youtube.com/results?search_query=m7rlin+discord+bot+tutorial+discord.js) *(search)*
M7rlin. A longer series: setup, commands, events and error handling, built up in order.

**Learn JavaScript first (if you're new)**
• [javascript.info](https://javascript.info): free modern JavaScript course
• [MDN JavaScript guide](https://developer.mozilla.org/en-US/docs/Web/JavaScript)

**Official docs (bookmark these)**
• [discordjs.guide](https://discordjs.guide): the official step-by-step guide
• [discord.js.org](https://discord.js.org): full API documentation
• [Discord Developer Docs](https://discord.com/developers/docs/intro)
• [Node.js](https://nodejs.org) and [pm2](https://pm2.keymetrics.io) for hosting
• [discord.js support server](https://discord.gg/djs) to ask questions

**How to watch tutorials well:** pause and type the code yourself instead of copying, and check the video date. Some older videos use discord.js v12 or v13, whose code no longer works in v14.
