# Step 7: Loading and deploying commands
Two jobs: **deploy** (tell Discord the commands exist) and **load** (let the bot find the code).

**deploy-commands.js** (run it whenever you add or change a command's *definition*)
```js
require('dotenv').config();
const { REST, Routes } = require('discord.js');
const fs = require('node:fs');
const path = require('node:path');

const commands = [];
const dir = path.join(__dirname, 'commands');
for (const file of fs.readdirSync(dir).filter(f => f.endsWith('.js'))) {
  commands.push(require(path.join(dir, file)).data.toJSON());
}

const rest = new REST().setToken(process.env.DISCORD_TOKEN);

(async () => {
  await rest.put(
    Routes.applicationGuildCommands(process.env.CLIENT_ID, process.env.GUILD_ID),
    { body: commands },
  );
  console.log(`Deployed ${commands.length} command(s).`);
})();
```
Run it once:
```
node deploy-commands.js
```
These are **guild commands**: they appear instantly in your test server. (Global commands use `Routes.applicationCommands(CLIENT_ID)` and can take up to an hour to show.)

**Loading in index.js** (add under the `client` line, and import `Collection`)
```js
const { Client, GatewayIntentBits, Events, Collection } = require('discord.js');
const fs = require('node:fs');
const path = require('node:path');

client.commands = new Collection();
const dir = path.join(__dirname, 'commands');
for (const file of fs.readdirSync(dir).filter(f => f.endsWith('.js'))) {
  const command = require(path.join(dir, file));
  client.commands.set(command.data.name, command);
}
```
Now every file you drop in **commands/** is picked up automatically.

**Checkpoint:** typing `/` in your server shows your bot's **ping** command.
