# Step 5: First login
Put this in **index.js**:
```js
require('dotenv').config();
const { Client, GatewayIntentBits, Events } = require('discord.js');

const client = new Client({
  intents: [GatewayIntentBits.Guilds],
});

client.once(Events.ClientReady, readyClient => {
  console.log(`Logged in as ${readyClient.user.tag}`);
});

client.login(process.env.DISCORD_TOKEN);
```

Run it:
```
npm start
```
You should see `Logged in as YourBot#0000` and the bot turns **online** in your server. Stop it any time with **Ctrl + C**.

**What each part does**
- `require('dotenv').config()` reads your `.env` into `process.env`
- `Client` is your connection to Discord
- `intents` say which events you want. `Guilds` is the basic one (servers, channels, roles, slash commands)
- `Events.ClientReady` fires once when the bot has logged in
- `client.login()` connects using your token

**If it fails**
- `TokenInvalid`: the token in `.env` is wrong, or has spaces/quotes. Reset it in the portal and paste again.
- `Used disallowed intents`: you asked for a privileged intent in code that isn't switched on in the portal (page 3).
- `Cannot find module`: you are in the wrong folder, or you skipped `npm install`.

**Checkpoint:** your bot shows as online.
