# Step 1: Install Node.js and VS Code
Your bot is a JavaScript program, and **Node.js** is what runs JavaScript outside a browser.

**Install Node.js**
1. Go to **nodejs.org** and download the **LTS** version (Node 20 or newer; discord.js v14 needs at least 18).
2. Run the installer and keep the defaults.
3. Open a terminal (Windows: search **Command Prompt** or **PowerShell**; Mac: **Terminal**) and check it worked:
```
node -v
npm -v
```
You should see version numbers like `v22.x.x`. If you see "not recognized", close and reopen the terminal, or restart your PC.

**Install a code editor**
Download **Visual Studio Code** from **code.visualstudio.com**. It is free and has a built-in terminal (**Terminal > New Terminal**).

**Useful VS Code extras**
- **Prettier**, formats your code neatly
- **ESLint**, warns you about mistakes
- Turn on **Format on Save** in settings

**Tip:** make one folder for all your projects, for example `Documents/bots`. You will create the bot's folder inside it on page 5.

**Checkpoint:** `node -v` prints a version of 18 or higher.
